# Glossary — POD EU OPC
- **POD:** Print on Demand
- **AOP:** All-Over-Print (in phủ toàn bộ sản phẩm, vd leggings)
- **OSS/IOSS:** One-Stop-Shop / Import OSS (VAT EU)
- **GPSR:** General Product Safety Regulation (EU)
- **ROAS:** Return on Ad Spend (target ≥2.5)
- **CPA:** Cost per Acquisition / per Purchase (target <$20)
- **AOV:** Average Order Value (target >$75)
- **CTR / CVR:** Click-Through Rate (>2%) / Conversion Rate (>2.5%)
- **CAPI:** Conversions API (Meta server-side tracking)
- **BM:** Business Manager (Meta Ads, cấu trúc 5 tầng chống ban)
- **ABO / CBO:** Ad Set / Campaign Budget Optimization
- **LAL:** Lookalike Audience
- **Profit-per-SKU:** lãi ròng từng sản phẩm sau phí
- **Gross margin gate:** ngưỡng biên lãi gộp ~45–55% (kinh tế ShopBase)
