# _skills-agents — 03-growth

3 AI Worker của phòng Growth, ma trận trách nhiệm và coverage trên 5 SOP.

## 1. AI Workers
| Worker | Trọng tâm | SOP responsible |
|--------|-----------|-----------------|
| `vibe-opc-pod-growth-fb-ads` | Meta Ads (ABO→CBO, 4-layer, CAPI, BM 5-tier, scale/kill) + growth report | **GRW-002, GRW-004** |
| `vibe-opc-pod-growth-fb-creative` | Ad creative (hook/body/CTA), UGC brief, carousel | **GRW-005** |
| `vibe-opc-pod-growth-marketing` | Email Klaviyo (opt-in/GDPR) + organic social/community | **GRW-003, GRW-001** |

## 2. Responsibility Matrix (Worker × SOP)
| SOP | fb-ads | fb-creative | marketing |
|-----|:------:|:-----------:|:---------:|
| GRW-001 Organic | C | C | **R** |
| GRW-002 FB Ads | **R** | C | I |
| GRW-003 Email | I | C | **R** |
| GRW-004 Report | **R** | C | C |
| GRW-005 Creative | C | **R** | I |

R = Responsible · C = Consulted · I = Informed. A (Accountable) = OPC cho mọi SOP.

## 3. Coverage check
- 5/5 SOP có đúng 1 Responsible worker → **không gap, không chồng chéo**.
- `fb-ads` gánh 2 SOP (002+004 — gắn chặt: vận hành ↔ đo lường).
- `marketing` gánh 2 SOP owned-channel (001+003).
- Cross-consult: creative ↔ ads (CTR/fatigue feedback); report ↔ tất cả (KPI/KRI).

## 4. Escalation
Mọi worker → OPC (Accountable) khi: vượt budget cap, BM ban, off-track O1, GDPR/policy issue → 05-compliance.
