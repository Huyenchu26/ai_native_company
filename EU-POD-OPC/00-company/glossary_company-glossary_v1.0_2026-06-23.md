# DAKOfits — Glossary

**Phiên bản:** 1.0 · **Ngày:** 2026-06-23

| Thuật ngữ | Định nghĩa |
|-----------|-----------|
| **POD** | Print-on-Demand — in theo yêu cầu, không tồn kho |
| **AOP** | All-Over-Print — in phủ toàn bộ bề mặt sản phẩm (legging 360°) |
| **Niche** | Ngách thị trường (nghề, sở thích, thú cưng, lối sống...) |
| **Winner** | SKU/creative đạt ROAS/CPA mục tiêu → đủ điều kiện scale |
| **Promote theo đợt** | SOP-MER-006: chọn 5–10 SP/đợt → tối ưu → ads → scale winner |
| **ROAS** | Return on Ad Spend = Revenue / Ad spend |
| **CPA** | Cost per Acquisition = Ad spend / số đơn |
| **Blended ROAS** | ROAS tính trên toàn bộ doanh thu & chi phí ads (không chỉ 1 campaign) |
| **ShopBase** | Nền tảng store DTC (dakofits.com) |
| **Printify / PrintBase** | Print provider (US + EU) fulfill AOP |
| **GPSR** | General Product Safety Regulation (EU) — bắt buộc cho đơn EU |
| **Responsible Person** | Pháp nhân EU chịu trách nhiệm sản phẩm theo GPSR |
| **GDPR** | General Data Protection Regulation (EU) — bảo vệ dữ liệu cá nhân |
| **OSS / IOSS** | One-Stop-Shop / Import OSS — cơ chế khai VAT EU |
| **CAPI** | Conversions API (Meta) — gửi event server-side, chống mất tín hiệu |
| **BM** | Business Manager (Meta) — quản lý tài khoản quảng cáo, anti-ban 5-tier |
| **LAL** | Lookalike Audience — tệp tương tự |
| **SLI/SLO/SLA** | Service Level Indicator / Objective / Agreement |
| **OKR/KRI/KPI** | Objectives & Key Results / Key Result Indicators / Key Performance Indicators |
| **SOP State Machine** | template → input → processing → output → archive |
